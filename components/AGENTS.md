# components

## Overview

All of the UI. The `ui/` folder holds the generated shadcn primitives, and the files at this level are app components. Some render on the server and take props, the rest are marked `'use client'`. The two heavy ones are the upload flow and the voice conversation.

## Key files

| File | Owns |
|---|---|
| `VapiControls.tsx` | Starts and ends the Vapi voice call, shows the transcript, the status, and the timer |
| `UploadForm.tsx` | Validates the form, uploads the PDF to Vercel Blob, parses it, then saves the book |
| `FileUploader.tsx` | A form file field bound with `useController` |
| `VoiceSelector.tsx` | The voice choice field, reading `voiceOptions` from `lib/constants.ts` |
| `BookCard.tsx`, `HeroSection.tsx`, `Search.tsx`, `Navbar.tsx`, `Transcript.tsx`, `LoadingOverlay.tsx` | Presentation |
| `ui/` | shadcn primitives, regenerated by the shadcn CLI |

## Conventions

- Add a primitive with the shadcn CLI. `components.json` sets style `base-nova`, base color `neutral`, lucide icons, and aliases to `@/components/ui` and `@/lib/utils`. Edit a generated primitive only to fix a real bug, so the next CLI run does not fight your change.
- Start an interactive file with `'use client'`. Keep data fetching in server components and server actions.
- Page level structure uses the classes defined in `app/globals.css`, for example `wrapper`, `library-books-grid`, `new-book`, `book-page-container`, and `vapi-stat-box`. Reach for Tailwind utilities for anything smaller.
- Brand colors come from `BRAND_COLOR` and `BRAND_COLOR_HOVER` in `lib/constants.ts`. They are written inline as `text-[#212a3b]` style values because these components sit where the CSS variables are not reachable from JavaScript.
- Icons come from `lucide-react`. Feedback to the user goes through `sonner` toasts.

## Gotchas

- `VapiControls` needs `NEXT_PUBLIC_VAPI_PUBLIC_KEY` and `NEXT_PUBLIC_ASSISTANT_ID`. It shows a readable error when either one is missing, so a broken call is usually a missing key rather than a bug in the component.
- The call is metered on the server. Start it through `startVoiceSession`, which is the only place a session row is created, and end it through `endVoiceSession` so the duration is recorded.
- File size and file type limits are checked twice: `UploadSchema` in the browser and `ALLOWED_CONTENT_TYPES` in `app/api/upload/route.ts`. Change the two together.
